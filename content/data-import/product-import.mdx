# 产品批量导入模板填写说明

> 支持语言：中文站、英文站（单次导入仅针对当前所选语言站点，请在上传前确认页面语言）

## 一、模板概述

本模板用于批量导入产品数据，支持 **父产品（parent）** 和 **变体（variant）** 两种类型。一次导入可同时创建多个产品及其变体，并自动关联分类、价格阶梯、图片、SEO 信息等。模板采用 Excel 格式（`.xlsx`），请严格按照以下列顺序填写。

### 模板列顺序（共 28 列）

| 列名 | 必填 | 类型 | 说明 |
|------|------|------|------|
| 一级分类 | 是 | 文本 | 产品所属的一级分类，需与系统中已有分类完全一致 |
| 二级分类 | 否 | 文本 | 产品所属的二级分类（若无二级分类，留空） |
| 产品类型 | 是 | 枚举 | `parent`（父产品）或 `variant`（变体） |
| SKU | 否 | 文本 | 唯一库存编码。父产品为空时系统自动生成；变体可留空自动生成 |
| 产品名称 | 是 | 文本 | 产品显示名称，建议长度 ≤128 字符 |
| Slug | 否 | 文本 | URL 友好标识符（小写字母、数字、连字符）。为空时自动根据产品名称生成拼音 |
| 品牌 | 否 | 文本 | 产品品牌。为空时使用系统“基本设置”中的默认品牌 |
| 简短描述 | 否 | 文本 | 产品核心卖点，建议 100–300 字符 |
| 详细描述 | 否 | HTML | 完整产品描述，支持 HTML 标签。系统会保留换行并转换为 `<p>` 标签 |
| 主图URL | 否 | URL | 产品主图网络地址。系统会自动下载并存储到服务器 `/uploads` 目录 |
| 附加图URL1 | 否 | URL | 第1张附加图，支持网络地址 |
| 附加图URL2 | 否 | URL | 第2张附加图 |
| 附加图URL3 | 否 | URL | 第3张附加图 |
| 附加图URL4 | 否 | URL | 第4张附加图 |
| 附加图URL5 | 否 | URL | 第5张附加图 |
| 附加图URL6 | 否 | URL | 第6张附加图 |
| 附加图URL7 | 否 | URL | 第7张附加图 |
| 附加图URL8 | 否 | URL | 第8张附加图 |
| 最小起订量1 | 条件必填 | 整数 | 第1个价格阶梯的最小购买数量，父产品必须填写至少一个阶梯 |
| 单价1 | 条件必填 | 数字 | 第1个阶梯对应的单价 |
| 最小起订量2 | 否 | 整数 | 第2个价格阶梯的最小数量（必须大于第1阶梯的最小数量） |
| 单价2 | 否 | 数字 | 第2个阶梯的单价 |
| 最小起订量3 | 否 | 整数 | 第3个价格阶梯的最小数量 |
| 单价3 | 否 | 数字 | 第3个阶梯的单价 |
| SEO关键词 | 否 | 文本 | 多个关键词用英文逗号分隔，建议 1–3 个核心词 |
| SEO标题 | 否 | 文本 | 浏览器标题，长度建议 30–60 字符，重要关键词前置 |
| SEO描述 | 否 | 文本 | 搜索引擎描述，长度建议 80–160 字符，通顺自然，包含核心关键词 |
| 规格说明 | 否 | 文本 | 商品规格，格式：`属性:值,属性:值`（例如：`颜色:黑色,尺寸:XL`） |

> **注意**：变体行（产品类型为 `variant`）**无需填写** 分类信息（一级/二级分类）以及价格阶梯。变体的分类、价格、库存状态等均继承自其关联的父产品。

## 二、父子产品关联规则

- 产品类型为 `parent` 的行，表示一个独立的主产品（可包含多个变体）。
- 产品类型为 `variant` 的行，表示该产品是**紧挨着上方最近的一个 `parent`** 的变体子产品。
- **示例**：  
  第1行：产品类型 `parent` → 创建父产品 A  
  第2行：产品类型 `variant` → 创建变体 A1，关联父产品 A  
  第3行：产品类型 `variant` → 创建变体 A2，也关联父产品 A  
  第4行：产品类型 `parent` → 创建新的父产品 B  

> ⚠️ 变体行不能独立存在。如果变体行上方没有父产品，导入时会报错。

## 三、各字段详细填写要求

### 3.1 分类（一级分类、二级分类）
- **一级分类**：必填，必须与系统后台已创建的“产品线”下的一级分类名称**完全一致**（区分大小写）。
- **二级分类**：选填。若产品没有二级分类，留空即可。填写时，名称必须与系统中该一级分类下的二级分类名称完全一致。
- 分类不存在时，导入会失败，需先到【产品分类管理】中创建。

### 3.2 SKU（库存单位）
- 父产品：若不填写，系统自动按规则 `P-8位随机数字` 生成（例如 `P-12345678`）。
- 变体：若不填写，系统自动按规则 `V-8位随机数字` 生成。
- **建议手动填写有意义的 SKU**，便于后续管理。SKU 在整个系统中必须唯一，重复会报错。

### 3.3 产品名称
- 必填，建议长度不超过 128 字符。
- 应清晰描述产品核心属性，例如：“小米官方防摔手机壳 - 透明超薄”。

### 3.4 Slug（URL 标识）
- 选填。若留空，系统会自动根据“产品名称”生成拼音 slug（例如 `xiao-mi-guan-fang-fang-shuai-shou-ji-ke`）。
- 允许字符：小写字母、数字、连字符（`-`）。禁止空格、下划线、特殊符号。
- 建议填写自定义 slug，使 URL 更简短、语义化。

### 3.5 品牌
- 选填。留空时，系统会使用【基本设置】中的默认品牌（默认 `Neutral`）。
- 若填写，请确保品牌名称与日常使用一致。Google 购物要求产品最好包含品牌信息。

### 3.6 简短描述
- 建议 100–300 字符，用 1–2 句话概括产品核心卖点、应用场景。
- 例如：“四角气囊防摔，透明超薄设计，支持无线充电。”

### 3.7 详细描述
- 选填，支持 HTML 标签。可以包含段落、列表、表格等。
- 若直接输入纯文本（不带标签），系统会自动将换行符转换为 `<p>` 标签。
- **建议**：内容充实（500–1000 字），包含产品特性、使用方法、材质、尺寸等，利于 SEO。

### 3.8 图片（主图 + 附加图1~8）
- 支持填写外部网络图片链接（以 `http://` 或 `https://` 开头）。
- 系统会自动下载图片并存储到服务器 `/uploads/` 目录，存储后使用本地路径。
- **建议**：主图使用 1:1 比例，分辨率不低于 600×600 像素；附加图展示多角度、使用场景、包装等。

### 3.9 价格阶梯（最小起订量+单价）
- **父产品必须至少填写一个阶梯**（第1阶梯的“最小起订量1”和“单价1”不能同时为空）。
- 阶梯数量最多 3 个。数量必须递增（例如 1、10、50），系统会自动处理 `max_qty`（上一阶梯的上限 = 下一阶梯的最小起订量 - 1，最后一个阶梯上限为无限制）。
- **示例**：
  - 阶梯1：最小起订量 `1`，单价 `10` → 买 1–9 件，每件 10 元
  - 阶梯2：最小起订量 `10`，单价 `9` → 买 10 件及以上，每件 9 元
- 单价保留两位小数（如 `9.99`）。

### 3.10 SEO 字段（关键词、标题、描述）
结合 Google 搜索引擎优化建议，请按以下规范填写：

#### SEO 关键词
- 选填。每个关键词 1–3 个单词，多个关键词用英文逗号 `,` 分隔。
- 只选择 1–2 个核心关键词，避免堆砌。
- 示例：`防摔手机壳,透明手机壳,小米手机壳`

#### SEO 标题
- 长度：30–60 字符（中文约 15–30 字）。
- 重要关键词尽量前置。
- 推荐结构：`主要核心关键词 - 次要关键词 | 品牌名`
- 示例：`防摔手机壳 - 透明超薄 | 小米官方`

#### SEO 描述
- 长度：80–160 字符。
- 用完整通顺的句子概括页面内容，自然包含 1–2 个核心关键词。
- 可加入行动号召，如“立即购买”、“查看详情”。
- 示例：`小米官方防摔手机壳，透明超薄设计，四角气囊缓冲，有效保护手机。多种机型可选，立即购买享一年质保。`

### 3.11 规格说明
- 格式：`属性:值,属性:值`（多个规格用英文逗号分隔）。
- 示例：`颜色:红色,尺寸:XL,材质:不锈钢`
- 用于在前台展示产品的具体规格参数。

## 四、系统自动处理的信息项

以下字段**无需在模板中填写**，系统会根据当前站点的【基本设置】自动填充：

| 字段 | 默认值来源 |
|------|----------|
| 上架状态 | `published`（上架） |
| 库存状态 | 基本设置中的“默认库存状态” |
| 运费 | 基本设置中的“默认运费” |
| 退货天数 | 基本设置中的“默认退货天数” |
| 关联模板 | `default_product_published` |
| MPN | 空字符串 |
| GTIN | 空字符串 |
| 货币 | 基本设置中的“默认货币” |
| `identifier_exists` | `false` |
| 基础价格（`price`） | 取价格阶梯中第1阶梯的单价 |
| 产品类型标签（`product_type`） | 拼接 `一级分类 > 二级分类`（若无二级分类，则仅为一级分类） |
| Google 产品类别 | `0`（未设置） |

> 若需要自定义这些值，请通过【基本设置】页面修改默认值，或手动编辑产品时单独调整。

## 六、常见问题与注意事项

1. **分类名称必须与系统中完全一致**  
   导入前请先确认分类名称（包括大小写、空格）。可在【产品分类管理】中查看。

2. **变体必须紧跟父产品**  
   变体行不能出现在文件开头，也不能在变体后出现新的父产品而前一个父产品的变体未结束。

3. **价格阶梯数量递增**  
   如果填写了阶梯2，其“最小起订量2”必须大于“最小起订量1”；阶梯3同理。否则系统报错。

4. **图片 URL 必须可访问**  
   系统会尝试下载图片，若网络地址无法访问或超时，该图片导入失败（产品仍会创建，但图片为空）。建议使用稳定、高速的图片链接。

5. **编码问题**  
   Excel 文件请保存为 `.xlsx` 格式，避免使用特殊字符导致解析错误。

6. **大文件处理**  
   单次导入建议不超过 500 行（产品数+变体数）。超过时请分批导入。

7. **导入后检查**  
   导入完成后，系统会返回成功/失败统计。请下载错误日志，修正后重新上传。
