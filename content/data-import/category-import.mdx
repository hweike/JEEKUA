# 产品分类批量导入模板填写说明

> 支持语言：中文站、英文站（单次导入仅针对当前所选语言站点，请在上传前确认页面语言）

## 字段说明

| 字段名称 | 必填 | 填写规则 |
|---------|------|----------|
| **产品线名称** | 选填 | 指定该分类所属的产品线（如：手机配件）。<br />• 若当前导入页面已选定产品线，可留空，系统自动关联。<br />• 若填写，请保证与系统中产品线名称完全一致。 |
| **一级分类名称** | **必填** | 一级分类的名称。<br />• 创建二级分类时，本字段可留空（系统将自动关联上一行的一级分类）。<br />• 纯一级分类行（无二级分类）必须填写本字段。 |
| **二级分类名称** | 选填 | 二级分类的名称。<br />• 填写时，无需重复填写“一级分类名称”，系统自动归到上方最近的一级分类下。<br />• 若留空，则表示该行仅用于维护一级分类信息或作为空行跳过。 |
| **分类描述** | 选填 | 分类的简要描述，用于前台展示或 SEO。<br />• 建议 100-200 字符，清楚说明该分类包含的产品类型。 |
| **Slug 名称** | 选填 | URL 友好的标识符，用于生成分类页面链接。<br />• 允许字符：小写字母、数字、连字符（`-`）<br />• 禁止字符：空格、下划线（`_`）、特殊符号（`@#!`等）<br />• 长度建议：51-100 字符<br />• 示例：`xiaomi-phone-accessories`<br />• 未填写时，系统将根据分类名称自动生成（拼音或英文）。 |
| **产品自定义属性模板** | 选填 | 为该分类绑定的属性模板 ID 或名称。<br />• 请预先在「产品目录 > 基本设置 > 自定义属性模板」中创建。<br />• 此处填写模板名称或 ID 均可，系统将自动匹配。<br />• 留空则表示不绑定额外属性模板。 |
| **封面图片 URL** | 选填 | 分类的展示图片（建议宽高比 16:9，分辨率 ≥ 600×400）。<br />• 支持填写网络图片地址（以 `http://` 或 `https://` 开头）。<br />• 系统将自动下载图片并上传至平台存储，无需手动上传。 |
| **SEO 关键词** | 选填 | 页面关键词，用于搜索引擎优化。<br />• 建议选择 1 个核心关键词，每个词 1-3 个单词。<br />• 多个关键词请用英文逗号（`,`）分隔，重要关键词靠前。<br />• 示例：`手机壳,防摔手机壳,iPhone手机壳` |
| **SEO 标题** | 选填 | 浏览器标题栏显示的标题。<br />• 长度建议：30-60 字符<br />• 重要关键词前置<br />• 推荐结构：<br />  「主要核心关键词 - 次要关键词 \| 品牌名」<br />  「产品名称 \| 品牌 \| 核心卖点」<br />• 示例：`防摔手机壳 - 透明超薄 | 小米官方` |
| **SEO 描述** | 选填 | 搜索引擎结果中显示的页面描述。<br />• 长度建议：80-160 字符<br />• 使用完整通顺的句子概括页面内容，自然包含 1-2 个核心关键词。<br />• 可加入吸引点击的行动号召（如“立即购买”、“查看详情”）。<br />• 示例：`小米官方防摔手机壳，透明超薄设计，四角气囊缓冲，有效保护手机。多种机型可选，立即购买享一年质保。` |

## 重要注意事项

1. **单语言导入**：一次导入仅针对当前选择的语言站点（中文或英文）。如需同时维护双语分类，请分别在上传前切换语言后再次导入。
2. **分类层级**：支持两级结构（一级分类 → 二级分类）。如需更深层级，请分多次导入或手动编辑。
3. **排序规则**：分类顺序以表格中出现的先后顺序为准（从上到下）。一级分类间、二级分类间的排序均按行顺序自动生成。
4. **唯一性校验**：同一产品线下，一级分类名称不允许重复；同一级分类下，二级分类名称不允许重复。
5. **覆盖与追加**：导入时默认**覆盖**当前语言站点下该产品线的所有分类数据。如需保留原有数据，请先导出备份。
6. **错误处理**：若表格中存在格式错误或逻辑错误（如二级分类找不到所属一级分类），系统将中止导入并提示具体行号，请修正后重新上传。
