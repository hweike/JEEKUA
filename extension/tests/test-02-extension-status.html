🧪 插件状态检测 v2.1

在商品页 Console 中执行检测代码，验证插件各模块状态

⚠️ 重要说明：
1. 此检测代码 必须在商品页的 Console 中执行（普通网页无法访问 chrome.runtime API）
2. 请先在插件中点击 「加载适配器」，否则适配器相关状态会显示为「未加载」

📋 测试步骤

1
打开商品页
在浏览器中打开阿里国际站或1688的商品详情页
2
加载适配器（必须）
点击插件图标 → 点击 「加载适配器」，等待加载完成
3
打开开发者工具
按 F12 或 ⌘+⌥+I，切换到 Console 标签
4
复制并执行检测代码
点击下方「📋 复制检测代码」，在 Console 中粘贴并回车

📝 检测代码 复制 → 粘贴到 Console

// ============================================================ // 插件状态检测代码 - 在商品页 Console 中执行 // ⚠️ 请先在插件中点击「加载适配器」 // ============================================================ console.log('🔍 ===== 插件状态检测 ====='); // 1. 检测 chrome.runtime const hasRuntime = typeof chrome !== 'undefined' && chrome.runtime; console.log('1. chrome.runtime 可用:', hasRuntime); if (!hasRuntime) { console.log('❌ 当前页面不在插件上下文中，请在商品页执行'); } else { // 2. Ping 测试 chrome.runtime.sendMessage({ action: 'ping' }, (response) => { console.log('2. ping 响应:', response); console.log(' lastError:', chrome.runtime.lastError); }); // 3. 获取详细状态 chrome.runtime.sendMessage({ action: 'getStatus' }, (status) => { console.log('3. getStatus 响应:', status); if (status && status.success) { console.log(' 平台:', status.platformId); console.log(' 支持采集:', status.isSupported); console.log(' 适配器已加载:', status.isLoaded); console.log(' 连接状态:', status.connectionStatus); } }); } // 4. 检测 window.__adapters console.log('4. window.__adapters:', window.__adapters); if (window.__adapters) { console.log(' 已加载:', Object.keys(window.__adapters)); } // 5. 检测悬浮窗 const hasFloatBtn = !!document.querySelector('.jeekua-float-btn'); console.log('5. 悬浮窗:', hasFloatBtn ? '✅ 已存在' : '⏳ 未加载'); // 6. 页面信息 console.log('6. 页面 URL:', window.location.href); console.log('🔍 ===== 检测完成 =====');
